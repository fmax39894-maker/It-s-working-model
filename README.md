# ❤️ It's Working Heart

A modern automatic Image & Video Gallery.

## Features

- Fullscreen Intro Video
- Automatic Image Gallery
- Automatic Video Gallery
- Fullscreen Viewer
- Download Button
- Floating Popup Image
- Search
- Mobile Friendly
- GitHub + Render Ready

## Installation

```bash
npm install
npm start
```

Server:

http://localhost:3000

Deploy:

- Push to GitHub
- Connect repository to Render
- Build Command:

npm install

- Start Command:

npm start
